# timer-offset

Small offline web app that calculates which delay offset (30-minute steps) to set on the washing machine so it finishes around a chosen time.

**Open the app:** https://luka-grabarevic.github.io/timer-offset/

## Install on Android

Open the link in Chrome, then **⋮ → Install app** / **Add to Home screen**. It works offline afterwards.

## Development

Plain static files in [`site/`](site/), no build step. Every push to `master` deploys to GitHub Pages via [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
